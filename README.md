# Sri Mahadeshwara Arts

A playful, modern React/Vite portfolio site for Sri Mahadeshwara Arts.

Highlights:
- Real workshop / storefront / vehicle / printing photos supplied by the business
- Hero image slideshow
- Portfolio gallery with filters and lightbox
- Bike & car stickers
- Digital printing
- Laser cutting
- CNC routing
- Letter bending
- Custom artwork
- Responsive mobile design
- GitHub Pages-friendly relative asset paths

Run:
npm install
npm run dev

Build:
npm run build
